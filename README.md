# PR2_algo

## Построение алгоритма и его реализация в виде программы

### Цель занятия

* анализировать поставленную задачу;
* строить алгоритм решения задачи;
* записывать алгоритм в виде блок-схемы и псевдокода;
* реализовывать алгоритм на языке программирования;
* тестировать и отлаживать программу.

### 1. Теоретические сведения

<b>Алгоритм</b> — конечная последовательность действий, приводящая к решению задачи.
Основные свойства алгоритма: дискретность, понятность, результативность, массовость, детерминированность.

#### Основные алгоритмические конструкции:

<b>Линейная</b> — действия выполняются последовательно.
<b>Ветвление</b> — выбор действий в зависимости от условия.
<b>Цикл</b> — многократное повторение действий.

<b>Способы записи алгоритма:</b>

* словесный;
* псевдокод;
* блок-схема;
* программа.

### 2. Задание

Пользователь вводит натуральное число `N`.

Необходимо вычислить сумму всех чётных чисел в диапазоне `от 1 до N` включительно.

Если введено число `N < 1`, вывести сообщение об ошибке.

### 4. Дополнительное задание

<b>Модифицируйте программу так, чтобы она дополнительно находила:</b>

* количество чётных чисел `от 1 до N`;
* сумму чисел, кратных `3`;
* максимальное чётное число, не превышающее `N`.
